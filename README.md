

## 项目简介

这是一个基于Vue 3 + Ant Design Vue的智能光伏停车场能源管理系统，提供实时监控、发电量预测、设备管理等功能。

## 主要特性

### 🎨 界面美化
- **现代化设计**：采用渐变背景和卡片式布局
- **响应式设计**：支持各种屏幕尺寸，移动端友好
- **统一视觉风格**：侧边栏、头部、仪表板保持一致的视觉语言

### 📊 图表优化
- **ECharts集成**：专业的图表展示，支持实时数据更新
- **布局优化**：解决图表和文字重叠问题
- **响应式图表**：自动适应容器大小变化

### 🔧 组件增强
- **ECharts组件**：支持加载状态、响应式调整、性能优化
- **侧边栏导航**：美观的深色主题，支持图标和动画效果
- **头部组件**：实时时间显示、用户状态、位置信息

## 技术栈

- **前端框架**：Vue 3 + Composition API
- **UI组件库**：Ant Design Vue
- **图表库**：ECharts 5
- **图标库**：Font Awesome
- **构建工具**：Vite
- **样式**：CSS3 + 渐变 + 动画

## 安装和运行

### 环境要求
- Node.js 16+
- npm 8+

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```
