# 人员管理功能说明

## 功能概览

人员管理页面整合了原来的用户权限管理和操作日志功能，提供了完整的用户管理解决方案。

## 主要功能

### 1. 用户管理
- ✅ **用户列表展示**：显示所有用户的基本信息
- ✅ **用户搜索**：支持按用户名搜索
- ✅ **添加用户**：管理员可以创建新的操作员账户
- ✅ **编辑用户**：修改用户基本信息和角色
- ✅ **重置密码**：管理员可以重置用户密码
- ✅ **删除用户**：删除不需要的用户账户（master用户受保护）

### 2. 操作日志
- ✅ **实时日志展示**：显示最近的操作记录
- ✅ **日志筛选**：按操作类型筛选日志
- ✅ **详细日志查看**：模态框中查看完整日志列表
- ✅ **日志导出**：支持导出操作日志

### 3. 统计数据
- ✅ **用户统计**：显示总用户数、管理员数量、操作员数量
- ✅ **活动统计**：显示今日操作次数

## 默认用户账户

### Master管理员
- **用户名**: `master`
- **密码**: `123`
- **角色**: 管理员
- **权限**: 完全管理权限，不可删除

### 示例用户
页面还包含了一些示例用户数据：
- `admin` (管理员)
- `operator1` (操作员)  
- `operator2` (操作员)

## 用户角色说明

### 管理员 (admin)
- 创建、编辑、删除用户
- 重置用户密码
- 查看所有操作日志
- 导出系统数据

### 操作员 (operator)
- 查看个人信息
- 执行日常操作任务
- 访问基本系统功能

## 安全特性

1. **密码加密存储**：所有密码都经过bcrypt加密
2. **用户保护**：master用户不能被删除或降级
3. **操作审计**：所有用户管理操作都会记录日志
4. **表单验证**：完整的前端表单验证

## 界面特色

1. **现代化设计**：使用Ant Design Vue组件
2. **响应式布局**：适配各种屏幕尺寸
3. **实时更新**：操作后立即更新界面
4. **友好交互**：丰富的动画和反馈效果

## 技术实现

- **前端框架**: Vue 3 + Ant Design Vue
- **路由管理**: Vue Router
- **状态管理**: Vue 3 Composition API
- **表单验证**: Ant Design Vue 表单验证
- **图标库**: Font Awesome

## 使用方法

1. 在侧边栏点击"人员管理"进入页面
2. 使用"添加用户"按钮创建新用户
3. 点击用户操作列的按钮进行编辑、重置密码或删除
4. 查看右侧的操作日志了解系统活动
5. 点击"查看全部"查看完整的操作日志列表

## 开发说明

页面位于 `frontend/src/views/PersonnelManagement.vue`，整合了原来的：
- `UserPermissions.vue` - 用户权限管理功能
- `OperationLog.vue` - 操作日志功能

路由配置已更新，侧边栏菜单已合并为单一的"人员管理"入口。
